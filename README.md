# 📚 Research Assistant — LLM · LangChain · FAISS · RAG

A **research assistant** built with **Streamlit**, **LangChain**, **FAISS**, **HuggingFace Embeddings**, and an **LLM served via OpenRouter**.

Upload one or more research papers (PDFs), ask questions about them using **RAG**, get structured summaries, and fall back to **General Knowledge Mode** automatically whenever a question isn't covered by the uploaded papers — no manual mode switching required.



## ✨ Features

### 📄 Research Paper Q&A (RAG)
- Upload multiple PDF research papers at once
- Automatic text extraction and intelligent chunking
- Semantic search over document chunks using FAISS
- Context-aware answers generated by an LLM, grounded strictly in retrieved text
- Numbered source citations (`[1]`, `[2]`, ...) mapped back to source chunks
- Retrieved-document viewer so you can see exactly what the model used

### 🤖 Multi-Agent Routing
Every query is routed to the agent best suited to handle it:

| Agent | Responsibility |
|---|---|
| 📄 Research Paper QA Agent | Answers questions grounded in the uploaded PDFs |
| 📑 Summarization Agent | Produces a structured summary of uploaded papers |
| 🌍 General Knowledge Agent | Answers questions unrelated to the uploaded papers |

### 📑 Document Summarization
Summarizes uploaded papers into a consistent structure:
- Main Objective
- Methodology
- Key Findings
- Conclusion

### 🌍 General Knowledge Fallback
If the router determines a question isn't a document-summary request, it's treated as a research question first — if there's no relevant paper context to draw from, the assistant answers from general LLM knowledge instead of returning "not found."

### 📚 Citation Support
Research-grounded answers include inline citations such as:

```
[1] Attention_Is_All_You_Need.pdf — Page 3
```

so you can trace every claim back to its source.

### 🔍 FAISS Semantic Search
Retrieval is powered by:
- `sentence-transformers/all-MiniLM-L6-v2` embeddings (HuggingFace)
- A local FAISS vector index for fast similarity search

Only the most relevant chunks are passed to the LLM, which keeps answers grounded and reduces hallucination.

### 📂 Multiple PDF Support
Upload a single paper or many — the assistant indexes and searches across all of them together, and lets you clear the uploaded set and rebuild the index at any time.

### ⚡ Optimized Retrieval Pipeline
- Recursive character text splitting (600-character chunks, 100-character overlap)
- Reference/bibliography pages are automatically filtered out before indexing
- Top-k similarity retrieval keeps prompts small and fast

## ⚙️ Installation

**1. Clone the repository**
```bash
git clone https://github.com/akshay2292004-sketch/multi-agent-research-assistant-llm-langchain-faiss-rag.git
cd multi-agent-research-assistant-llm-langchain-faiss-rag
```

**2. Create and activate a virtual environment**
```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

```bash
streamlit run streamlit_app.py
```

## 📋 How It Works

1. **Upload** one or more PDF research papers from the sidebar.
2. The app **extracts text**, strips reference/bibliography pages, **splits documents into chunks**, generates **embeddings**, and stores them in a local **FAISS index**.
3. **Ask a question** in the chat input — or ask it to summarize a paper.
4. The **router** decides whether the query is a summarization request or a question.
5. For questions, the app **retrieves the most relevant chunks**, generates a **grounded answer with citations**, and shows the retrieved source passages.
6. If the question isn't answerable from the uploaded papers, the assistant **falls back to general knowledge** automatically.
